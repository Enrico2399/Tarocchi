# PROJECT — Tarocchi Pro

## Visione
Trasformare l'app Tarocchi da prototipo funzionale a **studio di lettura digitale professionale** su Ionic React + Capacitor, pronta per Play Store.

## Milestone attuale
**Tarocchi Pro** — UX professionale, interpretazioni AI-first, zero testi hardcoded.

## Stack
- Ionic 8 + React 19 + TypeScript + Vite + Capacitor 8
- App canonica: `tarocchi-ionic/`
- Package: `com.enrico2399.tarocchi`
- Monetizzazione: Google AdMob

## Requisiti chiave
1. Interpretazioni generate da AI (on-device primary), mai paragrafi statici in `cardsData`
2. Toolbar unificata senza overlap bottoni
3. Web dev funzionante (lazy-load plugin nativi)
4. Cache interpretazioni per performance/offline parziale
5. `npm run verify` verde dopo ogni fase
