# UI BENCHMARKS — Esoteric tarot apps

| App | Strength | Borrow |
|-----|----------|--------|
| Golden Thread | Journal, clean arcana art | Panel spacing, serif titles |
| Labyrinthos | Educational, dark UI | Chip selectors, card grid |
| Galaxy Tarot | Classic spread layout | Table vignette |
| Co–Star (adjacent) | Poetic copy, minimal | Empty states, onboarding tone |

## Avoid
- Neon cyan pulses (current ArcanaDelGiorno)
- Flat Material toggles without theming
- Generic Ionic purple headers
