# DESIGN PRINCIPLES — Tarocchi Esoteric UI

## 1. Atmosphere first
Every screen sits inside a "chamber": vignette, grain, radial glow, never flat white.

## 2. Ritual hierarchy
Primary action = ceremonial CTA (gold ring, slow hover).
Secondary = ghost/sigil buttons (44px min).

## 3. Typography
- **Ritual:** Georgia serif — titles, arcanum names, spread chips active
- **Functional:** system-ui — settings labels, body legal

## 4. Color discipline
Only palette tokens. Gold = sacred highlight, never decoration spam.

## 5. Motion
Ease-out slow (0.45–0.85s). Respect reduced motion.

## 6. Accessibility
WCAG AA contrast on text; focus rings gold-lavender.

## Tokens (canonical)
See `tarocchi-ionic/src/theme/variables.css` + `esoteric.css`
